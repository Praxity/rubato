# Rubato 0.2.0

Rubato 0.2.0 is the first public release. It runs on Apple Silicon and Intel
Macs. Windows support is planned for the next release. To install, see
[Install Rubato 0.2.0](../../README.md#install-rubato-020).

## After you update

1. In each course you use with T3 Code, run `praxity init` again. Then, in T3's
   project Actions settings, delete each saved Praxity action and import it
   again from `t3.json`. The actions now set up course identity before they
   open Studio or export.
2. Export your published HTML and SCORM courses again to pick up the security
   fixes in exported pages (see Fixes below).

To update an earlier install, save your work, close every Studio tab, stop
Studio, then run `praxity update`.

## Changes that can stop an export

- Inline SVG `data:` images are now refused, because they can carry script.
  Use an image file, or a PNG or JPEG `data:` URL.
- HTML and SCORM exports refuse GIFs that flash rapidly, which can trigger
  seizures. The export names each GIF to replace.

## New

- `praxity update` installs the latest release. It checks downloads before
  switching, and keeps your current version if anything fails.
- Two new skills: Composer turns a brief into a course outline and coordinates
  writing and review. Assessment Writing helps you write distractors and
  feedback, and review items independently.
- Studio's review mode finds and resolves comments. Studio also adds lesson
  time, kickers and choice history.
- `praxity skills install --adopt` takes over skill folders you copied by
  hand. It lists the differences first; add `--yes` to confirm.
- `praxity init` hides Studio's identity and recovery files from VS Code's
  explorer and search. Your own VS Code settings stay as they are.
- With `--lang fr`, all of Studio's CLI messages, including errors, are in French.

## Fixes

- Skills you've edited are backed up to `~/.praxity/skill-backups/` before a
  refresh or uninstall replaces them.
- Rollback works on Intel Macs.
- A failed install or version check puts back the version you had.
- SCORM courses no longer overwrite a learner's saved progress when they can't
  read it from the LMS, or when a save fails.
- Exported pages block script hidden in links, in question text in group
  pickers, and in inline course data.
- Self-checks with `{deckGate=attempt}` export.
- Studio's editor shows saving and saved status beside the text you edit, and
  shows when discarded text is waiting for a fresh page. It explains a lesson's
  source errors and lets you edit again once you fix them. Typing a bullet at
  the start of a list item explains why to remove it. Long lesson titles no
  longer widen the page.
- When Studio's preview in T3 doesn't appear, the studio-editor skill explains
  why and how to open Studio another way.
- Check's reviewer stays on your computer unless you choose Codex
  (`--reviewer codex` or `--tier inference`). PDFs now default to
  accessibility checks, like HTML.
- Trace reads UTF-16 JSON files, such as those Windows PowerShell 5.1 saves,
  and UTF-8 files with a byte-order mark. Item-cue analysis defaults to
  masked-only; choices-only and cover-the-options need
  `prepare item-cues --diagnostics`.
- Rubato installs Node 24.22.1.
- The installer and links now use the Rubato name. The command is still `praxity`.

## Known limit

If other people have user accounts on your Mac, any of those accounts can get
Studio's editing link while Studio is running. Run Studio only on a Mac whose
other accounts you trust. A fix is planned for the next release.
